Help and keyboard tips

Using the keyboard

  • Tab and Shift + Tab move between links, fields and buttons.
  • The first Tab on any page shows a “Skip to main content” link.
  • Enter in any form field saves the form. On the marks form this is “Save and enter another”.
  • Arrow keys move between options in a group of radio buttons.
  • Esc closes a confirmation dialog without deleting anything.
  • In a table, select a column heading button to sort; select it again to reverse the order.

Entering a class’s marks quickly

  1. Go to Enter marks and choose the module and assessment type.
  2. Type the student number (or start typing their name) and the mark.
  3. Press Enter. The mark is saved, the module and assessment stay selected, and the cursor returns to the student number.

Grade boundaries and late work

Grade for each final mark
Final markGrade
70–100First
60–69Upper second (2:1)
50–59Lower second (2:2)
40–49Third
0–39Fail

Work up to 5 days late is capped at 40. Work more than 5 days late receives 0. Accepted mitigating circumstances remove the penalty.

Who can do what

Exam officers can add and edit students and marks. Administrators can also delete records.
